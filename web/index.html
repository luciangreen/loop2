What loop2 supports

  • Rule A — facts to list predicate: colour(red). colour(blue). → colours([red,blue]).
  • Rule B — findall/3 over a fact generator → explicit loop001/2 recursion
  • Rule C — nested findall + member/2 flattened into a single loop
  • Rule D — simple one-clause predicate body spliced inline
  • Transforms: Y is X * 2, Y = f(X), Y = [X,X], etc.
  • Explicitly rejects: !, ;, ->, \+, call/N, assert/retract, side-effects
